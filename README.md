# Football Table Ultimate

Tronbyt / Pixlet App fuer die 1. und 2. Bundesliga.

## Funktionen

- 1. Bundesliga
- 2. Bundesliga
- Liga-Auswahl
- dynamische Favoriten-Auswahl
- Vereinslogo
- aktuelle Tabelle
- letzte Ergebnisse
- naechstes Spiel
- Datum und Uhrzeit des naechsten Spiels
- OpenLigaDB API
- HTTP Cache
- 64x32 optimiert
